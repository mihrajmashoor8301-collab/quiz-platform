### Personal Live Quiz Platform

A free, self-hosted Mentimeter/Kahoot alternative for personal use (≤200 live participants).

- Next.js + React + Tailwind CSS frontend
- Node/Express backend with Socket.IO for real-time questions, answers, timers, leaderboard
- PostgreSQL (local cluster) with Supabase-style Edge Functions + Supabase Auth integration points
- 6-digit room PINs, nickname guest join, server-side validation, rate limiting, load tests
